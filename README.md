# VIBE // MOSH 9:16 — Vertical Kinetic Glitch, 3D Typography & Datamosh Studio

A browser-based mobile 9:16 datamoshing, kinetic 3D typography, pixel sorting, and photo ASCII art studio.

## Features
- **Kinetic 3D Typography**: Real-time perspective text in a 3D **Spiral** (helix), **Cube**, and **Sphere** with touch/mouse rotation and depth z-sorting.
- **P-Frame Datamosh & Smear**: Compression feedback simulation, macroblock video codec displacement, slice shear tearing, and real-time interactive Jam Pad.
- **Pixel Sorting**: Directional dripping (vertical), tearing (horizontal), and slanting (diagonal) sorted by luminance, saturation, or color channels.
- **Photo ASCII Art Engine**: Upload custom images or load built-in cyberpunk graphics, with real-time ASCII conversion (Blocks `█▓▒░`, Standard `@%#*`, Matrix, Binary, Katakana) and live datamoshing.
- **Color & Gradient Controls**: Dual-color text gradients, animated rainbow cycle, custom backdrop gradients, and an instant 8-palette generator.
- **Mobile Ergonomics**: Thumb-friendly rotary knobs with safe insets from screen borders, expanded touch hit targets, and pointer capture.
- **Export Studio**: High-res 9:16 PNG snapshot and direct 9:16 video recording (MP4/WebM).

## Deployment (Netlify)
This project is pure client-side HTML5/CSS/JavaScript with no build steps or dependencies required.
- **Publish Directory**: Root (`.`)
- **Entry File**: `index.html`
